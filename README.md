# סל חכם 🛒 — השוואת סל אמיתית בין חצי חינם, רמי לוי ושופרסל

תוסף כרום שמקבל רשימת קניות, בונה **עגלה אמיתית בכל אחד משלושת האתרים**, קורא את המחירים **מהאתר עצמו**,
ומראה איפה הסל הכי משתלם, כולל משלוח והנחות אישיות. בסוף יש כפתור "עבור לעגלה" לכל רשת, ונשאר רק לשלם.

> **סטטוס: גרסה 0.2, כוילה מול שלושת האתרים האמיתיים (20–21.11.2026).** התוסף מילא עגלות אמיתיות בחצי חינם, ברמי לוי
> ובשופרסל, והסכומים שהוא מציג שווים לסכומים באתרים ([docs/SITES.md](docs/SITES.md)). כשאתר משתנה, דף **האבחון**
> מפיק דוח (בלי מידע אישי) לתיקון מהיר.


🎬 **סרטון הסבר קצר (40 שניות):** [promo/sal-hacham-reel.mp4](promo/sal-hacham-reel.mp4)

## מה זה עושה

| קלט | פלט |
|---|---|
| התחברות לכל רשת (באתר עצמו, התוסף לא רואה סיסמה) | עגלה מלאה בכל רשת |
| רשימת קניות בטקסט חופשי | סה"כ לכל רשת: מוצרים (מהאתר) + משלוח − הנחות אישיות |
| כתובת, הנחות מועדון/כרטיס אשראי, דמי משלוח ידניים (אופציונלי) | המלצה: הסל המשתלם ביותר, ולמה |
| | השוואה שורה-אחר-שורה: זהה / דומה / שונה / חסר, ומה הזול ביותר |
| | מבצעים ששווה לשקול, מוצרים שהתייקרו, "אולי שכחת" |
| | כפתור **"עבור לעגלה"** לכל רשת |

המוצרים נבחרים לפי היסטוריית הקניות (מה שרגילים לקנות), ואפשר להחליף כל בחירה לפני מילוי העגלות. התוסף זוכר את ההחלפות.

## התקנה

המדריך המלא, צעד-אחר-צעד ובעברית פשוטה: **[docs/INSTALL.md](docs/INSTALL.md)**. בקצרה (Windows + Google Chrome, גרסה 0.2.0):

1. הורידו את **[מתקין סל חכם (SalHacham-Setup.cmd)](https://github.com/Marku-a/Claude-Market-online/releases/latest/download/SalHacham-Setup.cmd)**.
   אם כרום או Windows מזהירים שהקובץ "לא נפוץ", בחרו **שמור** ואחר כך **מידע נוסף** ← **הפעל בכל זאת**. זה צפוי, והקובץ פתוח לקריאה ובטוח (פרטים במדריך).
2. הריצו אותו בלחיצה כפולה. חלון שחור קצר ייפתח, וזה תקין. המתקין מוריד את הגרסה העדכנית מ-GitHub, שם אותה בתיקייה
   קבועה (`%LOCALAPPDATA%\SalHacham\extension`), מעתיק את הנתיב שלה ללוח, ופותח את כרום עם דף הוראות בעברית.
3. בכרום, בדף `chrome://extensions`, שלוש לחיצות (בפעם הראשונה בלבד, כי כרום לא מאפשר להתקין תוסף מחוץ לחנות באופן אוטומטי):
   הפעילו **מצב מפתח** (Developer mode) ← **טען פריט לא ארוז** (Load unpacked) ← הדביקו (Ctrl+V) את הנתיב בשורת הכתובת של החלון,
   Enter, ו**בחר תיקייה** (Select Folder).
4. לחצו על סמל הפאזל 🧩 ו**נעצו** את "סל חכם" לסרגל.
5. התחברו בלשוניות רגילות לשלושת האתרים (ודאו שמוגדרת כתובת משלוח בכל אחד), פתחו את התוסף ופעלו לפי השלבים.
   התשלום תמיד על ידכם באתר.

עדכון: מריצים שוב את `SalHacham-Setup.cmd` ולוחצים ↻ על סל חכם. הסרה: [SalHacham-Uninstall.cmd](https://github.com/Marku-a/Claude-Market-online/releases/latest/download/SalHacham-Uninstall.cmd).
ב-Mac/Linux, או אם המתקין לא עובד, יש התקנה ידנית: [docs/INSTALL.md](docs/INSTALL.md).

## אבטחה
ראו **[docs/SECURITY.md](docs/SECURITY.md)**. בקצרה:
- לתוסף יש גישה **רק** לשלושת אתרי הרשתות. הוא עצמו חסום מלשלוח מידע לכל מקום אחר (אין שרת).
- הוא **לא נכנס לדפי תשלום ולא מבצע הזמנה**. אין בקוד פעולה כזאת, וכתובות קופה/תשלום חסומות.
- לא רואה ולא שומר סיסמאות או פרטי אשראי. הנתונים נשמרים רק במחשב שלכם, ויש כפתור מחיקה.

## מגבלות ידועות
- **נבדק מול האתרים האמיתיים ב-20–21.11.2026**: בשלוש הרשתות התוסף מילא עגלה אמיתית (רשימות של 2 ו-3 פריטים, מדיניות
  "להשאיר ולהוסיף"), והסכומים במסך התוצאה שווים לסכומים שהאתרים מציגים. פרטים ב-[SITES.md](docs/SITES.md).
- **התאמת מוצרים**: כשאין ברקוד זהה, הבחירה לפי שם עלולה לבחור מוצר אחר (למשל "אטריות ביצים" עבור "ביצים").
  מוצר כזה מסומן "שונה" בטבלה, אבל עדיין נכלל בסכום. בדקו את מסך הבדיקה לפני מילוי העגלות.
- **חצי חינם**: "עבור לעגלה" פותח את דף הבית, ושם לוחצים "העגלה שלי" (דף העגלה שלהם נמצא תחת /checkout/, ולכן
  התוסף לא נכנס אליו). מינימום ההזמנה נבדק מול הסכום כולל משלוח. היסטוריית ההזמנות אינה כוללת כמויות (כל מוצר נספר
  כ-1). ריקון עגלה נלקח מהקוד של האתר ועוד לא הורץ מולו.
- **רמי לוי**: "עבור לעגלה" פותח את דף הבית, והעגלה בחלונית בצד. לפני שבוחרים מועד משלוח באתר, דמי המשלוח ידועים
  רק כשיש מוצרים בעגלה.
- **שופרסל**: ההתחברות נשמרת רק לזמן הגלישה. אחרי סגירת הדפדפן צריך להתחבר שוב.
- כתובת המשלוח ומועד המשלוח נקבעים באתר של כל רשת. התוסף לא משנה אותם.

## מבנה הריפו

```
extension/            התוסף (MV3, בלי build ובלי תלויות)
  app/                הממשק (עברית, RTL) ו"המנצח" שמריץ את התהליך
  engine/             מנוע ההחלטות: העדפות מהיסטוריה, בחירת מוצר, השוואה והמלצה
  sites/              מתאם לכל רשת + שומר הסף (guard) שחוסם דפי תשלום
  diag/               דף אבחון + השחרת מידע (redaction)
  background.js       ניהול הלשוניות של האתרים
docs/                 SPEC, SITES (ממשקי האתרים ורמת הוודאות), SECURITY, INSTALL
tests/                engine, adapters, app (יחידה) · e2e (התוסף האמיתי בכרומיום מול אתרים מדומים)
.claude/skills/hatzi-hinam-shopper/   הגרסה הראשונה: סקיל ל-Claude לחצי חינם בלבד
```

## בדיקות

```bash
npm test                 # מנוע + מתאמים + תהליך
node --test --test-concurrency=1 tests/e2e/*.spec.mjs   # קצה-לקצה (דורש Playwright + Chromium)
python3 -m unittest discover -s tests                   # מנוע הסקיל המקורי
```

בדיקות הקצה-לקצה מריצות את התוסף האמיתי כשכתובות שלושת האתרים ממופות לשרת מדומה מקומי, ומוודאות בין השאר:
שלוש עגלות מתמלאות והסכומים נקראים מהאתר, אף בקשה לא יוצאת למקור אחר, אין נגיעה בכתובת checkout, והאסימון של
האתר לא נשמר ולא מופיע בדוח האבחון.

## הדגמה (בלי התקנה ובלי התחברות)

`demo/` בונה דף אחד שמריץ את הממשק האמיתי של התוסף מול שלוש רשתות מדומות שחיות בתוך הדף (מוצרים ומחירים מומצאים).
הדף מראה את כל התהליך, מרשימה ועד השוואה והמלצה. הוא לא מתחבר לאתרים האמיתיים ואינו הוכחה שהתוסף עובד מולם.

```bash
npm i --no-save esbuild        # כלי בנייה להדגמה בלבד, התוסף עצמו נשאר בלי תלויות
node demo/build.mjs node_modules/.bin/esbuild      # יוצר demo/dist/sal-hacham-demo.html
```
