# Claude Market Online 🛒

סקיל ל-Claude שמכין עגלת קניות מוכנה לתשלום בסופר אונליין. מתחילים ב**חצי חינם**.

אתם נותנים רשימת קניות, ו-Claude:
- קורא את היסטוריית ההזמנות שלכם ולומד מה אתם קונים (מותגים, כמויות, כל כמה זמן)
- מחפש כל פריט באתר ובוחר את **המוצר שאתם רגילים לקנות**
- מדווח מה **חסר** או אזל מהמלאי
- מציע **מבצעים ששווים** (למשל "2 ב-12" על מוצר שאתם ממילא קונים)
- מציע **החלפות** זולות יותר, ומסביר למה
- מתריע על **מוצרים שהתייקרו** מאז הקנייה האחרונה
- מזכיר מה **אולי שכחתם** (מוצרים קבועים שהגיע הזמן לקנות) ומה **בדרך כלל נקנה יחד**
- ממלא את העגלה **ועוצר**. התשלום נשאר אצלכם.

## איך זה עובד

```
רשימה ──► Claude בדפדפן שלכם ──► היסטוריה + תוצאות חיפוש ──► planner.py ──► דוח + אישור ──► עגלה מלאה
```

- **הדפדפן שלכם**: האתר מוגן ב-Cloudflare ולא נגיש מסקריפט בשרת. לכן Claude עובד בדפדפן שלכם (Claude in Chrome או
  הדפדפן המובנה באפליקציית Claude לדסקטופ). **אתם מתחברים בעצמכם**, וסיסמה לא נשמרת בשום מקום.
- **מנוע החלטות** (`scripts/planner.py`): Python בלי תלויות. מקבל היסטוריה, רשימה ותוצאות חיפוש, ומחזיר תוכנית עגלה
  ודוח בעברית. אפשר לבדוק ולהריץ אותו בנפרד.
- **הנתונים האישיים** נשמרים רק אצלכם ב-`~/.hatzi-hinam-shopper/`.

## התקנה

1. התקינו את [Claude Code](https://claude.com/claude-code) (או את אפליקציית Claude לדסקטופ) והתקינו/הפעילו את
   **Claude in Chrome**.
2. אחת מהאפשרויות:
   - לפתוח את Claude Code בתיקיית הריפו הזה. הסקיל ב-`.claude/skills/` נטען אוטומטית.
   - להתקין לכל הפרויקטים:
     ```bash
     cp -r .claude/skills/hatzi-hinam-shopper ~/.claude/skills/
     ```
3. להיכנס ל-shop.hazi-hinam.co.il בכרום ולהתחבר למשתמש שלכם.

## שימוש

> היי Claude, תעשה לי קניות בחצי חינם:
> 2 חלב 3%, לחם אחיד, ביצים L, עגבניות, קוטג', במבה ×3, נייר טואלט

Claude יציג דוח, ישאל שאלה אחת על ההחלפות והמבצעים, ימלא את העגלה ויגיד "העגלה מוכנה, נשאר רק לשלם".

## הרצת המנוע לבד (עם נתוני דוגמה)

```bash
cd .claude/skills/hatzi-hinam-shopper
python3 scripts/planner.py plan --history examples/history.json --list examples/list.txt \
  --candidates examples/candidates.json --today 2026-11-09
```

בדיקות (משורש הריפו):
```bash
python3 -m unittest discover -s tests -v
```
