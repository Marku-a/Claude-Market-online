# התקנה ושימוש — סל חכם

## התקנה (פעם אחת, כ-3 דקות)

1. הורידו את הריפו למחשב (Code → Download ZIP ופתחו את הקובץ, או `git clone`).
2. בכרום פתחו `chrome://extensions`.
3. הפעילו **מצב מפתחים** (Developer mode) בפינה העליונה.
4. לחצו **טען תוסף לא ארוז** (Load unpacked) ובחרו את התיקייה `extension` שבתוך הריפו.
5. הצמידו את "סל חכם" לסרגל (סמל הפאזל ← נעץ).

## שימוש

1. לחצו על סמל התוסף. נפתח דף "סל חכם".
2. **הגדרות** (בפעם הראשונה): כתובת, הנחות מועדון/כרטיס לכל רשת, ודמי משלוח ידניים אם רוצים.
3. **חיבור**: לכל רשת לחצו "פתח את האתר להתחברות" והתחברו באתר כרגיל. ודאו שכתובת המשלוח באתר נכונה.
   חזרו ולחצו "בדוק שוב".
4. **רשימה**: כתבו פריט בכל שורה (`2 חלב 3%`, `לחם אחיד`, `במבה x3`).
5. **בדיקה**: התוסף מראה איזה מוצר בחר בכל רשת. אפשר להחליף מוצר, לשנות כמות או להוריד שורה.
6. **תוצאה**: סה"כ לכל רשת (מוצרים + משלוח − הנחות), ההמלצה, וכפתור **"עבור לעגלה"** לכל רשת.
   התשלום נעשה על ידך באתר.

## אם משהו לא עובד

האתרים משתנים מדי פעם. בתחתית הדף יש קישור **אבחון**: הריצו אותו, לחצו "העתק דוח" ושלחו את הדוח.
הדוח מכיל רק מבנה (שמות שדות), בלי מחירים, שמות או פרטים אישיים. ראו [SECURITY.md](SECURITY.md).

## מגבלות ידועות (גרסה 0.2)

- **נבדק מול האתרים האמיתיים ב-20–21.11.2026**: בשלוש הרשתות התוסף מילא עגלה אמיתית (רשימות של 2 ו-3 פריטים, מדיניות
  "להשאיר ולהוסיף"), והסכומים במסך התוצאה שווים לסכומים שהאתרים מציגים. פרטים ב-[SITES.md](SITES.md).
- **התאמת מוצרים**: כשאין ברקוד זהה, הבחירה לפי שם עלולה לבחור מוצר אחר (למשל "אטריות ביצים" עבור "ביצים").
  מוצר כזה מסומן "שונה" בטבלה, אבל עדיין נכלל בסכום. בדקו את מסך הבדיקה לפני מילוי העגלות.
- **חצי חינם**: "עבור לעגלה" פותח את דף הבית, ושם לוחצים "העגלה שלי" (דף העגלה שלהם נמצא תחת /checkout/, ולכן
  התוסף לא נכנס אליו). מינימום ההזמנה נבדק מול הסכום כולל משלוח. היסטוריית ההזמנות אינה כוללת כמויות (כל מוצר נספר
  כ-1). ריקון עגלה נלקח מהקוד של האתר ועוד לא הורץ מולו.
- **רמי לוי**: "עבור לעגלה" פותח את דף הבית, והעגלה בחלונית בצד. לפני שבוחרים מועד משלוח באתר, דמי המשלוח ידועים
  רק כשיש מוצרים בעגלה.
- **שופרסל**: ההתחברות נשמרת רק לזמן הגלישה. אחרי סגירת הדפדפן צריך להתחבר שוב.
- כתובת המשלוח ומועד המשלוח נקבעים באתר של כל רשת. התוסף לא משנה אותם.
