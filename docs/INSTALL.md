# התקנה ושימוש — סל חכם

## התקנה (פעם אחת, כ-3 דקות)

1. הורידו את הריפו למחשב (Code → Download ZIP ופתחו את הקובץ, או `git clone`).
2. בכרום פתחו `chrome://extensions`.
3. הפעילו **מצב מפתחים** (Developer mode) בפינה העליונה.
4. לחצו **טען תוסף לא ארוז** (Load unpacked) ובחרו את התיקייה `extension` שבתוך הריפו.
5. הצמידו את "סל חכם" לסרגל (סמל הפאזל ← נעץ).

## שימוש

1. לחצו על סמל התוסף. נפתח דף "סל חכם".
2. **הגדרות** (בפעם הראשונה): כתובת, הנחות מועדון/כרטיס לכל רשת, ודמי משלוח ידניים אם רוצים.
3. **חיבור**: לכל רשת לחצו "פתח את האתר להתחברות" והתחברו באתר כרגיל. ודאו שכתובת המשלוח באתר נכונה.
   חזרו ולחצו "בדוק שוב".
4. **רשימה**: כתבו פריט בכל שורה (`2 חלב 3%`, `לחם אחיד`, `במבה x3`).
5. **בדיקה**: התוסף מראה איזה מוצר בחר בכל רשת. אפשר להחליף מוצר, לשנות כמות או להוריד שורה.
6. **תוצאה**: סה"כ לכל רשת (מוצרים + משלוח − הנחות), ההמלצה, וכפתור **"עבור לעגלה"** לכל רשת.
   התשלום נעשה על ידך באתר.

## אם משהו לא עובד

האתרים משתנים מדי פעם. בתחתית הדף יש קישור **אבחון**: הריצו אותו, לחצו "העתק דוח" ושלחו את הדוח.
הדוח מכיל רק מבנה (שמות שדות), בלי מחירים, שמות או פרטים אישיים. ראו [SECURITY.md](SECURITY.md).

## מגבלות ידועות (גרסה 0.1)

- **טרם נבדק מול האתרים האמיתיים.** הפיתוח נעשה מול אתרים מדומים לפי תיעוד של הממשקים (ראו [SITES.md](SITES.md)),
  כי האתרים חוסמים גישה משרתים. ההרצה הראשונה אצלכם היא הבדיקה האמיתית. צפו לסבב תיקונים.
- **חצי חינם**: ריקון עגלה, הפחתת כמות והיסטוריית הזמנות עדיין לא נתמכים (הממשקים לא מתועדים). אם יש מוצרים
  קודמים בעגלה, רוקנו אותה באתר לפני ההרצה.
- **רמי לוי**: היסטוריית הזמנות ברמת מוצר עדיין לא נתמכת.
- כתובת המשלוח נקבעת באתר של כל רשת. התוסף לא משנה אותה.
